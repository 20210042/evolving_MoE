# 한 배치의 유효 hard error 예측

hard error = **로스터 전원이 못 푼 문제**. 스카우트는 이것만 본다.
너무 많으면 무엇을 고를지 알 수 없고, 너무 적으면 새 전문가를 만들 근거가 없다.
판정: EM(현행) / ROUGE-L > 0.5
