# SNI 프로브 v2 — 두 축 로스터의 반복측정 이원 ANOVA

요인 = 문제 × expert, 반복 = K=3회 재생성. K가 있어 **오차(재생성 흔들림)를 따로 떼어**
상호작용과 구분한다. 점수 = 닫힘 EM / 열림 ROUGE-L.

- **상호작용**이 로스터가 존재할 이유다 — 문제에 따라 잘하는 expert가 갈리는 몫.
- **만장일치 제외** = 그 로스터 안에서 전원이 똑같은 점수를 낸 문제를 뺀 것.
