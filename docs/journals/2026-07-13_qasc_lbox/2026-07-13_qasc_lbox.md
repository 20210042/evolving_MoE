## Debugging History

- QASC smoke evaluation initially exposed runtime setup issues:
  - `vllm` missing when conda was not activated correctly.
  - `transformers.set_seed` import path pulled in PEFT/Accelerate and failed on `clear_device_cache`.
  - CUDA was touched before vLLM fork startup, causing CUDA reinitialization errors.
  - FlashInfer sampler failed on the available GPU stack; disabling it fixed vLLM startup.
- Full baseline evaluations completed:
  - QASC baseline job `206165`
  - LBox baseline job `206166`
- LUCA evaluations completed:
  - QASC LUCA job `206176`
  - LBox LUCA job `206177`
- 4090/A6000 exploratory LUCA jobs failed because their nodes reported an old NVIDIA driver for the current PyTorch/vLLM build. Those failed logs were removed from the main logs folder after the PRO6000 runs succeeded.
- Full-dataset SFT jobs were submitted but failed immediately:
  - QASC SFT job `206167`
  - LBox SFT job `206169`
  - Root cause: `ImportError: cannot import name 'clear_device_cache' from 'accelerate.utils.memory'`
  - This should be fixed before running full or persona-specific SFT.

## Interpretation

- LUCA slightly outperformed the dataset-specialized baseline prompt on both QASC and LBox in these vanilla Llama3 full-split runs.
- The QASC difference is small but nontrivial: +1.40 pass-score points.
- LBox absolute scores are very low under both prompts. LUCA is better by +0.58 points, but this should not be interpreted as strong legal-task competence.
- For subsequent SFT comparisons, the prompt mode should be treated as an experimental variable rather than an implementation detail.

## Caveats

- `pass_score` is exact-match style scoring for these tasks; it does not capture partial legal correctness.
- LBox answers may require stricter formatting and Korean legal terminology; prompt choice alone is unlikely to solve the low absolute score.
- Code changes are currently uncommitted. Use `provenance/uncommitted_prompt_system_diff.patch` together with commit `33ea692...` to reproduce this exact state.
- Initial full-dataset SFT jobs did not run due to the PEFT/Accelerate mismatch.
